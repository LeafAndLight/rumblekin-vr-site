# Rumblekin VR — GitHub Pages

Site estático baseado no kit visual V1, sem dependências e pronto para publicação pelo GitHub Pages.

1. No GitHub, abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch publicada e a pasta **/docs**.
4. Use a URL pública terminada em `/privacy/` no campo **Privacy Policy URL** do Meta Horizon Developer Dashboard.

O site usa caminhos relativos, funciona em repositório com subcaminho e inclui:

- landing page responsiva com inglês como idioma padrão;
- logo Rumblekin V1 integrada no cabeçalho, política e rodapé;
- tipografia Troika na identidade do jogo;
- parallax em camadas com alternativa para movimento reduzido;
- seletor com inglês, português, espanhol, francês, chinês simplificado e hindi;
- política de privacidade completa nos seis idiomas, com inglês como versão oficial;
- escolha de idioma preservada entre a landing page e a política;
- caminho direto de retenção e exclusão de dados.

O contato oficial usado no site é `leafandlightcontac@gmail.com`. Antes de publicar, confirme apenas a URL pública final do GitHub Pages.
